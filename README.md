# 词屿 · Ciyu Study

用于 Obsidian 桌面端的划词翻译、主动搜词、词汇归档与间隔复习插件。包含可调节透明度的 Liquid Glass 界面、离线词族分析、六级真题导入和听力精听。

## 安装

未安装 Obsidian 时，请先从 [Obsidian 官网](https://obsidian.md/download) 下载并安装桌面版，然后打开或创建一个笔记库。

### 手动安装

1. 从 [GitHub Releases](https://github.com/yannie2025/ciyu-study/releases/latest) 下载 `ciyu-study-plugin.zip`。解压安装包，把其中的 `ciyu-study` 文件夹放进当前库的 `.obsidian/plugins/`。如果库使用自定义配置目录，把它放进该目录的 `plugins/`。
2. 在 Obsidian 中打开「设置 → 第三方插件」。开启第三方插件，刷新列表后启用 **Ciyu Study**。
3. 如需 AI 翻译，从 [Ollama 官方下载页](https://ollama.com/download) 安装并启动 Ollama。在「设置 → Ciyu Study」执行「检测」，在推荐模型旁点「下载」，最后点「运行测试」。默认模型是 [Qwen2.5 1.5B](https://ollama.com/library/qwen2.5:1.5b)，下载约 986 MB。已有本地模型可从列表切换，或者填写模型名称后下载。
4. 点左侧工具栏的翻译图标，或从命令面板打开「Ciyu Study: 搜词翻译」。

使用源码时，进入项目目录运行 `npm ci` 和 `npm run build`。安装所需文件位于 `dist/ciyu-study/`。构建需要 Node.js 20 或更新版本，运行插件时无需 npm。macOS 源码构建还需要 Xcode Command Line Tools 来编译有道系统服务和 PDF 文字识别组件。发布 ZIP 包含离线词库和 macOS 辅助程序。

已安装旧版时，先禁用插件，将安装包内文件覆盖到原 `ciyu-study` 目录，保留里面的 `data.json`，再启用插件。归档笔记仍保存在原目录。

## 新功能

- 日常查词先查本地词库，直接显示英汉释义、音标与已有词形。有需要时点「AI 补充解析」。未收录的单词立即显示选项。英文整句在回车或划选查询时直接调用本地模型，只生成译文。较短句子可用「翻译句子」明确进入整句模式。
- 安装包自带八套离线词库，包括常用英汉、CET-4、CET-6、高考、考研、雅思、托福和 GRE，常用英汉词库默认启用。可添加、设为首选或移除，不影响已保存的生词。独立词库包也可以下载留档。
- macOS 下可选择「有道桌面」「Easydict」或「系统词典」。有道走 macOS 的“查询选中内容”系统服务。Easydict 使用官方 URL scheme，需先安装该客户端。查词结果在相应 App 中显示。[Easydict 官方发布](https://github.com/tisfeng/Easydict/releases)
- 「设置 → 搜索本机模型」会检测 Ollama、默认端口的 LM Studio 和常见本机 OpenAI 兼容服务。点击「接入」即可切换。本机 Ollama 中已安装的模型可以在设置中删除，确认后会真正从 Ollama 移除，其他使用同一个 Ollama 的应用也会受影响。模型可以重新下载。
- 「归档 → 管理笔记」可在「词屿/笔记」新建 Markdown，管理该目录及每日归档。「删除」移到「词屿/回收站」。「撤销最近操作」或同名命令可撤销本次插件运行期间的写入、创建和删除。若笔记随后被编辑，撤销会停止以保留后续内容。

## 用法

- **六级题库**。在词屿的「题库」里点「导入样卷或其他试卷」，可在当前 Obsidian 库中选择文件夹或输入新目录。默认保存到 `词屿/六级题库/文字版`。导入完成后会自动打开笔记，之后也可以点「打开上次导入的文字版」。
- **批量下载历年真题**。进入「题库 → 批量下载历年真题」，勾选 2024 年 6 月至 2026 年 6 月的试卷并选目标文件夹。词屿从南京大学公开自测页下载内容，将试题、参考答案和解析转换为 Markdown，可按目录跳转，答案默认折叠。目标文件夹会生成「六级真题下载索引」；已导入的套卷可以离线阅读，听力音频使用来源链接。
- **试卷导入**。macOS 可一键下载并识别官方六级笔试样卷，包含试题、听力文字稿和参考答案。也可导入 HTTPS 直链或批量选择本地 PDF、TXT、Markdown，单个文件上限为 32 MB。其他 PDF 需要有可选中的文字。历年试卷网页入口保存在题库索引。

- **划词**。编辑模式和阅读模式都可在选中文字后点浮出的「翻译选中内容」。编辑模式也可以右键选择「词屿：翻译选中文字」。命令面板中的「翻译选中文字」也可以设置快捷键。浮窗可固定到侧栏。
- **搜词**。在右侧栏或命令面板打开查词面板，输入词语或句子，按 Enter。查询成功后可以先编辑再保存。模型不可用时，错误区提供「手动填写」。
- **插入笔记**。确认结果下方显示的目标文件。编辑中的笔记在查询开始时记录的光标或选区末尾插入，原文保留。阅读模式或未打开的笔记追加到末尾。如提示文档已变化，用插入目标文件链接重新选择目标。
- **液态玻璃**。跟随 Obsidian 浅色和深色主题，并支持窄侧栏渐进布局。可从侧栏顶栏切换玻璃，或在「设置」调整透明度、边缘折射和动态效果。
- **每日归档**。「保存到今日」写入 `词屿/每日词汇/YYYY-MM-DD.md`，目录可改。右侧栏「归档」按日期列出笔记，在笔记里可直接新增、修改或删除 Markdown 词条。
- **收藏与复习**。生词本支持手动添加、搜索、编辑、删除和来源笔记跳转。同一原词可以保留不同释义。新卡立即可复习，点击「揭晓释义」后选择评分，系统更新到期时间。「原句挖空」优先使用来源句，有完全匹配的例句时也可用来挖空。忘记后 10 分钟重练，按天安排的卡片从到期日零点起可复习。
- **朗读**。查词、划词、生词本和复习均显示「朗读」。重复点击停止。macOS 调用系统 `say`，按文本选择英语或普通话语音，缺失时使用系统默认。其他桌面平台依赖 Obsidian 环境的 Web Speech 及系统语音。
- **Anki**。在生词本点「导出 Anki」，到库的 `词屿/导出/` 取 TSV 文件。使用 Anki 的「导入」，把 Front 和 Back 对应到正面和反面。同词多义时可选择把重复词条作为新笔记导入。[Anki 文本导入指南](https://docs.ankiweb.net/importing/text-files.html)

AI 翻译请求发送到本机 `127.0.0.1` 的 Ollama 端口，发送内容为所查词句和已启用的局部上下文。点击桌面词典按钮只会把当前查询交给选中的 App。第三方 App 是否联网取决于它的设置。笔记和导出文件在库中，生词与复习记录保存在插件目录的 `data.json`。备份或更新插件时保留该文件。

## 验证

`npm test` 覆盖写入竞争、失败后重试、归档、保留原选区、间隔调度、原句挖空、导出、模拟 Ollama HTTP 协议、搜词后插入、划词后收藏、旧数据兼容与外观设置。另用 Chromium 在 300px 侧栏下验证浅色、深色及主要界面操作，使用模拟 Obsidian Vault 和 Ollama。测试需要在本机临时绑定一个环回端口。

Obsidian 桌面端验收时，先在独立库安装插件。分别执行编辑模式右键划词、阅读模式划词、主动搜词之后插入、保存到今日、添加和删除生词、复习评分、打开导出文件，并重开 Obsidian 核对数据。连接真实 Ollama 测试模型输出，停止 Ollama 后查看手动录入和复习是否仍可用。
